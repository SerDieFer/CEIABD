# Especialización en Inteligencia Artificial y Big Data

Repositorio de prácticas de la especialización de **Inteligencia Artificial y Big Data (1CESIABD)**.

Aquí se organiza el código desarrollado en las asignaturas. Cada carpeta reúne las prácticas y notas técnicas breves de una materia. El repositorio acompaña el aprendizaje de programación, inteligencia artificial y sistemas de datos a gran escala.

## Asignaturas

| Carpeta | Asignatura | Enfoque |
|---|---|---|
| [`bda/`](bda/README.md) | Big Data Aplicado (BDA) | Gestión, almacenamiento, transformación y análisis de grandes volúmenes de datos. |
| [`mia/`](mia/README.md) | Modelos de Inteligencia Artificial (MIA) | Métodos y aplicaciones de IA, como búsqueda, aprendizaje automático, lenguaje natural, sistemas expertos y robótica. |
| [`pria/`](pria/README.md) | Programación de Inteligencia Artificial (PRIA) | Lenguajes, herramientas y desarrollo de soluciones y aplicaciones de IA. |
| [`saa/`](saa/README.md) | Sistemas de Aprendizaje Automático (SAA) | Preparación de datos, entrenamiento y evaluación de modelos de aprendizaje automático. |
| [`sbd/`](sbd/README.md) | Sistemas de Big Data (SBD) | Arquitecturas, almacenamiento y procesamiento distribuido de datos. |

## Organización del código

- Cada asignatura tiene su propia carpeta en la raíz.
- El código se divide por tema y tarea cuando se asignen prácticas, siguiendo los nombres `tema_01_<nombre>/tarea_<numero>_<nombre>/`.
- Los README de cada asignatura resumen qué se guarda en su carpeta.
- Las guías docentes, temarios, ejercicios originales y grabaciones se conservan en el archivo local del curso y no se publican aquí.
- No se crean carpetas de tareas ni soluciones antes de que se asigne o solicite cada práctica.

## Convenciones

Usa nombres de carpetas y archivos en minúsculas, con caracteres ASCII y formato `snake_case`. Mantén las extensiones en minúsculas. No incluyas credenciales, datos personales, materiales docentes con restricciones ni conjuntos de datos voluminosos.
